# 三期开发清单

> 该文档为历史阶段记录。GeoJSON 体检模块已经从后续稳定版范围中下线，当前产品范围以 README、发布清单和 `requirement/` 目录为准。

## 1. 项目包导入增强

状态：已完成。

- 已支持项目包导入前预览项目、AI 历史和 API 请求数量。
- 已支持导入冲突策略：覆盖冲突、跳过冲突、另存新项目。
- 已补充导入结果明细表，展示每条记录成功、跳过或失败原因。

## 2. AI 工作流增强

状态：已完成。

- 已支持从 AI 历史中心把历史 Prompt 转为模板。
- 已支持 AI 历史收藏与收藏筛选。
- 已支持 AI 上下文文件导入。
- 已支持按项目配置默认 Prompt 模板。

## 3. API 测试增强

状态：已完成。

- 请求集合分组。
- 已支持项目 API 自动发现。
- 已支持 Spring Controller 扫描，按 Controller 分组。
- 已支持扫描 DTO / 实体字段，为 `@RequestBody` 和疑似实体参数自动生成 JSON Body 草稿。
- 已支持前端 fetch / axios 调用扫描，按来源文件分组。
- 已支持异步扫描后预览并导入请求集合。
- 已支持响应断言：状态码、JSONPath、字段存在性。
- 已支持 OpenAPI / Swagger JSON 导入。
- 已支持项目级环境变量隔离，旧全局变量作为项目首次使用时的默认值。
- 已支持扫描结果和导入后的请求集合按分组折叠展示。
- 已支持相对路径接口统一保留 `{{baseUrl}}` 前缀。

## 4. Git 助手增强

状态：已完成。

- 已支持多文件批量暂存 / 取消暂存。
- 已支持提交前 AI 审查 diff。
- 已支持按项目保存 Git 分析历史。
- 已支持生成变更说明 Markdown。

## 5. 使用体验与稳定性

状态：已完成。

- 已支持多模型平台配置：SiliconFlow、OpenAI、DeepSeek 和 OpenAI 兼容平台。
- 已支持 API Key 保存到 `.env`，避免敏感信息写入 SQLite。
- 已完成窗口与页面自适应布局优化。
- 已补充导入、导出、分析等耗时操作的状态提示。
- 已补充 Ctrl+数字 快捷键导航。
- 已补充响应式布局回归静态检查。

## 6. 测试与发布

状态：已完成。

- 已补充三期功能回归脚本，覆盖数据迁移、项目包导入明细、上下文导入、快捷键和响应式检查。
- 已补充数据库迁移静态检查。
- 已补充项目包导入导出能力静态检查。
- 已补充打包产物验证脚本 `verify:build`。
