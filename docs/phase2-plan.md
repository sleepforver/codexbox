# 二期开发清单

## 1. 项目工作区

状态：已开始。

- 新增 `workspace_projects` 数据表。
- 支持维护项目名称、目录、说明、标签、创建时间、更新时间和最近使用时间。
- 新增项目工作区页面。
- 新增 `projects` IPC API。

## 2. 按项目关联数据

状态：已开始。

- AI 历史支持关联项目。

- Git 默认目录可从项目工作区选择。
- 后续需要继续补充项目维度导出和历史中心筛选。
