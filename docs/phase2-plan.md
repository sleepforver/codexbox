# 二期开发清单

## 1. 项目工作区

状态：已完成基础闭环。

- 新增 `workspace_projects` 数据表。
- 支持维护项目名称、目录、说明、标签、创建时间、更新时间和最近使用时间。
- 新增项目工作区页面。
- 新增 `projects` IPC API。
- 支持项目列表导入导出。

## 2. 按项目关联数据

状态：已完成基础闭环。

- AI 历史支持关联项目。
- API 请求集合支持关联项目。
- API AI 分析历史支持关联项目。
- Git 默认目录可从项目工作区选择。
- AI 历史中心支持按项目筛选、清空和保留重新执行记录的项目归属。
- 后续需要继续补充项目维度导出。

## 3. 地理数据管理

状态：已开始。

- GeoJSON 体检结果保存到 SQLite。
- 支持按项目查看地理数据检查历史。
- 已支持按项目清空和删除地理体检历史。
- 已增加基础要素、点要素、线要素和综合数据字段模板。

## 4. 批量导入导出

状态：已开始。

- 项目维度打包导出项目元数据、AI 历史、API 请求和地理体检历史。
- 支持项目数据包导入。

## 5. 使用体验增强

状态：已开始。

- 最近使用项目快捷入口。
- 页面按项目自动带入默认目录。
- 后续继续补充更细粒度的错误提示和空状态。
